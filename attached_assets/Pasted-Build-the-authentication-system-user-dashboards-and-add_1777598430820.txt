- Grid layout showing:
  * Lesson title
  * Brief description
  * Duration
  * Difficulty level
  * "Start Lesson" button

- No login required to view

- Interactive quiz to determine English/IELTS level
- Questions: 15-20 multiple choice questions
- After completion, show:
  * Student's level (A1, A2, B1, B2, C1, C2)
  * Recommendations for which course to take

  * Bonus structure
  * Payment terms

- Show affiliate resources (coming soon):
  * Marketing materials (images, videos)
  * Sample copy
  * Tracking links (build later)

## 5. SIGN UP PAGE (/signup)
- Registration form with fields:
  * Full Name
  * Email
  * Phone Number
  * Password (with strength indicator)
  * Confirm Password
- "Sign Up" button
- Link to "Already have an account? Log In"
- Form validation (email format, password strength, etc.)
- After successful signup:
  * Store user in database (PostgreSQL)
  * Send verification email via SendGrid
  * Redirect to login page with success message

## 6. LOG IN PAGE (/login)
- Email and password fields
- "Log In" button
- "Forgot Password?" link
- Link to "Don't have an account? Sign Up"
- Form validation
- After successful login:
  * Create session/JWT token
  * Redirect to student dashboard

## 7. PASSWORD RESET
- Forgot password page (/forgot-password)
- User enters email
- SendGrid sends reset link
- Reset password page (with new password form)
- Redirect to login after successful reset

## 8. FAQ SECTION (DYNAMIC - on landing page)

  * Quick stats:

  * Profile section:
    - View/edit name, email, phone
    - Change password
    - Logout button
  * Assessment results (if student took assessment)
  * Affiliate status (if applied to affiliate program)

## 10. ADMIN DASHBOARD (/admin)
- Secure admin login (separate from student login)
- Admin panel with:
  * Dashboard overview:
    - Total students
    - Total revenue
    - Total enrollments
    - Recent signups (last 10)
  * Manage Students:

    - View all enrollments

  * Manage FAQ:

  * Affiliate Applications:

  * View Analytics:

## 11. DATABASE SCHEMA (PostgreSQL)
Tables needed:
- users (id, name, email, phone, password_hash, created_at, role: 'student' or 'admin')
- enrollments (id, user_id, course_id, enrolled_date, status: 'pending' or 'active', payment_id)
- courses (id, name, price, description, course_type: 'ielts' or 'english')
- faqs (id, question, answer, order, created_at, updated_at)
- emails_sent (id, to_email, subject, content, sent_date)
- assessments (id, user_id, level, score, created_at)
- free_lessons (id, title, description, content, difficulty, course_type, created_at)
- affiliate_applications (id, name, email, phone, social_handles, why_join, status: 'pending' or 'approved' or 'rejected', applied_date)

## 12. EMAIL INTEGRATION (SendGrid)
Send automated emails for:
- Email verification (after signup)
- Welcome email (after successful first login)
- Course enrollment confirmation
- Password reset
- Admin notifications (new enrollment, payment received, affiliate application)
- Affiliate approval/rejection
- FAQ updates (optional)

## 13. SECURITY
- Hash passwords (bcrypt)
- JWT tokens for authentication
- Protect admin routes (only admin role can access)
- Protect student routes (only logged-in students can access)
- CSRF protection
- Rate limiting on login attempts
- Email verification for signups
