Integrate LEXO for IELTS with EduLexo platform using tier-based content filtering.

## INTEGRATION POINTS

1. STUDENT DASHBOARD (edulexo.com/dashboard)
   - Add "LEXO for IELTS" card after enrollment
   - Show tier (Advanced / Complete / Comprehensive)
   - Button: "Launch LEXO" → /lexo-ielts/dashboard

2. LEXO DASHBOARD (/lexo-ielts/dashboard)
   - Pull student data from edulexo auth
   - Auto-populate name, exam date
   - Show "My Plan" sidebar
   - Display onboarding (name, plan, exam date)

## TIER-BASED CONTENT FILTERING (UI LEVEL)

All tiers load full content. Apply filtering:

TIER 1: ADVANCED (B1-C1)
├─ Delete A2/B1 content → DISABLED
├─ When student clicks A2/B1:
│  └─ Show message: "هذا مخصص للمتقدم والشاملة"
│     (This is for Advanced and Comprehensive tiers)
└─ B1-C1 content: ENABLED

TIER 2: COMPLETE (B1-C1)
├─ Delete A2/B1 content → DISABLED
├─ When student clicks A2/B1:
│  └─ Show message: "هذا مخصص للمتقدم والشاملة"
└─ B1-C1 content: ENABLED

TIER 3: COMPREHENSIVE (A2-C1)
├─ All content: ENABLED
└─ No restrictions
